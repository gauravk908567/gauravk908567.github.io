# bugs.md

Tracks known issues with the portfolio site. Update status as bugs are fixed.

## Status Labels
- `open` — identified, not yet fixed
- `in-progress` — actively being worked on
- `fixed` — resolved (include the date and commit/change reference)
- `wont-fix` — acknowledged but intentionally left as-is

## Bug Template

```
### [BUG-XXX] Short description
- **Status:** open
- **Page/File:** which HTML file or section
- **Description:** What is wrong
- **Steps to reproduce:** How to see the bug
- **Expected:** What should happen
- **Actual:** What actually happens
- **Fixed in:** (fill when resolved — date + brief description of fix)
```
